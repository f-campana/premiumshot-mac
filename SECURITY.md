# Security

Please report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/f-campana/premiumshot-mac/security/advisories/new), once enabled for this repository. If unavailable, contact the maintainer through the profile linked on this repository. Do not put screenshots containing private information in a public issue.

PremiumShot processes images locally. The beta has no networking, analytics, account or automatic updater. Website and support links open in the default browser only after a user action.

Private-beta downloads are ad-hoc signed and not notarized. Signing and update validation will change when Developer ID distribution is introduced; see [release process](docs/release-process.md).
