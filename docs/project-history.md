# Project history

This Mac source project was extracted from the original shared workspace. Its two baseline commits are retained. The earlier design specs and historical captures remain in that archive; they are not build dependencies.

The original app reached 0.1.5 (7) before extraction. An unpublished 0.1.6 review used the new repository's commit count, yielding build 4. Release preparation replaced that rule with a recorded date-based build number so extraction or rebuilding cannot reverse update ordering. The permanent product identifier is `app.premiumshot.mac`.
