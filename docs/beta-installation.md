PremiumShot — private beta
==========================

Requires macOS 26. This package is for Apple Silicon.

Drag PremiumShot to Applications, then open it. This private beta is ad-hoc
signed and is not notarized. If macOS blocks it, open System Settings →
Privacy & Security and use Open Anyway for PremiumShot after checking that
the download came from the maintainer. macOS may ask for administrator
authentication. Do not disable Gatekeeper or remove quarantine globally.

PremiumShot shows a short welcome on first launch and then lives in the menu
bar. Copy a screenshot, press Command-Option-Shift-Space and press Return.
Paste and drop need no screenshots-folder permission. Open latest screenshot
may ask to read your screenshots folder; if access is declined, paste/drop
still work and the panel offers Privacy Settings and a folder picker.

Ad-hoc updates may prompt for folder access again; this must be checked on a
second Mac. There is no automatic updater yet: quit the app before replacing
it in Applications.

Feedback: email support@premiumshot.app with the steps, macOS version and
app version from About. Send private screenshots by email; never post them
in a public issue.

This candidate uses the permanent app identifier app.premiumshot.mac.
When replacing the earlier development app (com.fabien.premiumshot), expect
the welcome and appearance defaults again. Disable Open at Login in the old
app before replacing it, then enable it in the new app if wanted. macOS may
ask for screenshots-folder permission again.
